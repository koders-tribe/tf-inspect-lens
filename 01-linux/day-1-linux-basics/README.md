# Day 01 - Linux Basics

## Objective
Learn the basic Linux commands and understand the Linux file system.

---

## Topics Covered

- Linux Introduction
- File System
- pwd
- ls
- cd
- mkdir
- rmdir
- touch
- cp
- mv
- rm
- cat
- clear
- history

---

## Commands Practiced

| Command | Purpose | Example |
|----------|----------|----------|
| pwd | Shows current directory | pwd |
| ls | Lists files | ls |
| ls -l | Detailed list | ls -l |
| mkdir | Creates a directory | mkdir devops |
| touch | Creates a file | touch notes.txt |
| cp | Copies files | cp file1 file2 |
| mv | Moves/Renames files | mv file1 file2 |
| rm | Removes files | rm notes.txt |

---

## Hands-on Exercises

### Exercise 1
