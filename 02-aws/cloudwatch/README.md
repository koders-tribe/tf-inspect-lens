# Amazon CloudWatch

## Objective

The objective of this module is to understand Amazon CloudWatch, learn how to monitor AWS resources and applications, and perform basic hands-on exercises.

---

# What is Amazon CloudWatch?

Amazon CloudWatch is an AWS monitoring and observability service that collects metrics, logs, and events from AWS resources and applications. It helps monitor performance, troubleshoot issues, and create alerts.

---

# Why CloudWatch?

* Monitor AWS resources in real time.
* Collect application and system logs.
* Track CPU, memory, and network usage.
* Create alarms for resource utilization.
* Troubleshoot application and infrastructure issues.

---

# Key Concepts

## Metrics

Metrics are performance data collected from AWS resources.

Examples:

* CPU Utilization
* Network In
* Network Out
* Disk Read Operations

---

## Logs

CloudWatch Logs store application and system logs.

Examples:

* EC2 Logs
* Application Logs
* Lambda Logs

---

## Alarms

CloudWatch Alarms notify users when a metric crosses a specified threshold.

Examples:

* CPU Utilization > 80%
* Disk Usage > 90%

---

## Dashboard

A CloudWatch Dashboard provides a visual view of metrics, logs, and alarms.

---

## Events

CloudWatch Events (Amazon EventBridge) allow automatic actions based on specific AWS events.
