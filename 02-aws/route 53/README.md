# Amazon Route 53

## Objective

The objective of this module is to understand Amazon Route 53, learn how DNS works in AWS, and perform basic hands-on exercises.

---

# What is Amazon Route 53?

Amazon Route 53 is AWS's scalable Domain Name System (DNS) web service. It routes user requests to applications and AWS resources using domain names.

---

# Why Route 53?

* Register domain names.
* Manage DNS records.
* Route traffic to AWS resources.
* Perform health checks.
* Improve application availability.

---

# Key Concepts

## Domain Name

A domain name is the human-readable name of a website.

Examples:

* example.com
* mywebsite.in

---

## Hosted Zone

A Hosted Zone stores DNS records for a domain.

---

## DNS Records

DNS records define how traffic is routed.

Common records:

* A Record
* CNAME Record
* MX Record
* TXT Record

---

## Routing Policy

Routing policies determine how Route 53 directs user traffic.

Examples:

* Simple Routing
* Weighted Routing
* Latency Routing
* Failover Routing

---

## Health Check

Health Checks monitor application availability and automatically route traffic if a server becomes unavailable.
